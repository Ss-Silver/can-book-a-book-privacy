# 개인정보처리방침 (Privacy Policy)

**서비스명**: 책 빌릴수있어? (Can Book a Book)  
**시행일자**: 2026년 9월 29일  

'책 빌릴수있어?'(이하 "확장 프로그램")는 사용자의 개인정보를 매우 소중하게 생각하며, 사용자의 권익을 보호하고 크롬 웹스토어 개발자 프로그램 정책을 준수하기 위해 다음과 같이 개인정보처리방침을 공개합니다.

---

## 1. 개인 식별 정보의 미수집 원칙
본 확장 프로그램은 사용자의 어떠한 **개인 식별 정보(이름, 이메일 주소, 전화번호, 생년월일, 결제 카드 정보 등)**도 수집, 저장, 또는 외부 서버로 전송하지 않습니다. 회원가입 없이 누구나 즉시 이용할 수 있습니다.

---

## 2. 데이터 처리 및 브라우저 권한 사용 범위

확장 프로그램이 동작하기 위해 사용하는 최소한의 데이터 및 브라우저 권한은 다음과 같습니다.

### ① 로컬 저장소 (`storage` 권한)
* **목적**: 사용자의 편의를 위한 설정값 유지
* **보관 데이터**:
  - 사용자가 선택한 관심 도서관 목록 (도서관 코드 및 명칭)
  - 최근 도서 검색 기록 (최근 10건)
  - 일일 무료 조회 크레딧 사용량 상태
  - Pro 라이선스 인증 키 (Pro 사용자의 경우)
* **저장 위치**: 사용자의 기기 내부 로컬 브라우저(`chrome.storage.local`)에만 안전하게 저장되며, 개발자나 외부 서버로 전송되지 않습니다.

### ② 서점 웹페이지 도서 메타데이터 인식 (`activeTab`, `scripting` 권한)
* **목적**: 온라인 서점 도서 상세 페이지에서 대출 조회를 위한 도서 정보 자동 인식
* **동작 방식**: 사용자가 온라인 서점(교보문고, YES24, 알라딘) 도서 페이지에서 확장 프로그램 팝업을 열었을 때, 일시적으로 현재 탭의 DOM에서 도서명 및 13자리 ISBN을 읽어옵니다.
* **보관 여부**: 추출된 도서 정보는 일시적인 메모리(RAM)에서만 처리되며, 사용자의 웹 서핑 기록이나 방문 페이지 URL 등은 일체 기록하거나 추적하지 않습니다.

### ③ 도서관 소장 여부 조회 API 통신 (`host_permissions`)
* **목적**: 국립중앙도서관 '도서관 정보나루'를 통한 실시간 소장 및 대출 가능 여부 조회
* **통신 대상**: 공식 백엔드 프록시 서버 (`http://140.83.85.156`)
* **전송 데이터**: 조회하고자 하는 도서의 **ISBN** 및 **도서관 코드** (개인 식별 정보 일체 미포함)

---

## 3. 개인정보의 제3자 제공 및 위탁
본 확장 프로그램은 사용자의 데이터를 상업적 목적으로 제3자에게 판매, 양도, 공유하지 않으며, 전용 목적(도서관 대출 조회) 이외의 용도로 사용하지 않습니다.

---

## 4. 사용자 활동 추적 및 쿠키(Cookie)
본 확장 프로그램은 광고 식별자, 구글 애널리틱스 등 사용자의 행동이나 웹 활동을 추적하는 서드파티 트래커 및 쿠키를 전혀 사용하지 않습니다.
